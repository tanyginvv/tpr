# ТПР: оптимальный объём закупки

Интерактивное решение задачи о ежедневной закупке скоропортящегося продукта. Сайт содержит полное условие, 10 разделов и 40 шагов расчёта.

## Запуск

Откройте **`index.html`** в обычном браузере. Это автономный файл: интернет, установка зависимостей и сервер не требуются.

Для просмотра исходной версии с отдельными файлами откройте `src/index.html`. При необходимости запустите любой статический HTTP-сервер в папке репозитория.

## Порядок объяснения

Наблюдения → вероятности → прибыль одного дня → матрица → средняя прибыль → выбор закупки → проверки другими способами. Основной пример: купили 2 единицы, спрос оказался равен 1. Новые обозначения объясняются перед формулами; сложность и сравнение с перебором показаны отдельным заключительным шагом каждого метода. История, источники и дополнительные выкладки доступны в раскрываемых справках.

## Возможности

- Пошаговое раскрытие расчётов с переходами вперёд и назад.
- Выбор закупки и спроса с пересчётом дневной прибыли.
- Интерактивная матрица прибыли для 16 сочетаний.
- Основное решение по критерию Байеса—Лапласа; критерий отделён от алгоритма прямого перебора.
- Динамическое программирование с расшифровкой формулы и ползунком числа дней.
- Критерий Ходжа—Лемана с ползунком доверия, точным порогом 40/51 и корректной обработкой двух равноценных закупок на границе.
- Интерактивная матрица упущенной выгоды с выбором закупки и спроса, ожидаемые потери и ценность совершенной информации.
- Краткая суть каждого подхода и ссылки на конкретные страницы предоставленных учебников.
- Развёрнутые расчёты всех закупок, самостоятельный раздел ожидаемых потерь, расшифровка формулы Беллмана.
- Отдельный шаг сложности для каждого метода: обозначения, происхождение оценки и сравнение с прямым перебором; раскрывать справку не требуется.
- Поддержка клавиатуры и мобильного экрана.

Выбор данных сохраняет текущий шаг. Удержание клавиши и двойной клик не вызывают нескольких переходов. Кнопки браузера «Назад» и «Вперёд» восстанавливают предыдущие шаги.

При переключении шагов внутри раздела сохраняется позиция прокрутки. Начало страницы открывается при переходе в другой раздел.

## Проверки и сборка

Нужен Node.js 18 или новее. Устанавливать пакеты не требуется.

```sh
node verify.mjs
node scripts/build-standalone.mjs
```

Также доступны команды `npm test` и `npm run build`.

После изменения файлов в `src/` пересоберите `index.html`.

Проверки охватывают 16 прибылей и 16 потерь, эквивалентность точных расчётов для 503 распределений, ценность совершенной информации, 1001 значение доверия и точную границу равенства. Проверяются все 40 шагов в обоих направлениях, история браузера, защита от повторных нажатий, оба ползунка.

## Условие и результат

Цена закупки — 50 руб./ед., продажи днём — 60 руб./ед., продажи остатка вечером — 30 руб./ед. Спрос 1, 2, 3, 4 наблюдался соответственно 15, 30, 30, 25 раз.

По максимуму ожидаемой прибыли оптимально закупать **2 единицы**. Ожидаемая прибыль — **15,50 руб./день** при сохранении оценённого распределения спроса.


На сайте оставлены четыре подхода из предоставленных книг: Байес—Лаплас с прямым перебором, ожидаемые потери, динамическое программирование и Ходж—Леман.

## Учебная основа

- Черноморов Г. А. «Теория принятия решений», 2002: с. 168–169 (вероятностные модели), с. 251 (матрица рисков и средние потери), с. 253 (критерии при неизвестных вероятностях).
- Родзин С. И. «Теория принятия решений: лекции и практикум», 2010: с. 138–139, 145–146 (вероятности и Байес—Лаплас), с. 146 (учебная форма Ходжа—Лемана), с. 167 (ценность информации).
- Грешилов А. А. «Математические методы принятия решений», 2-е изд., 2014: с. 185–189 и 204 (динамическое программирование), с. 316–317 (полезность, потери и средний риск).
- Peterson M. *An Introduction to Decision Theory*, 2009: §1.3, с. 5–7 (PDF 16–18); §4.1, с. 65–66 (PDF 76–77).

Исходная задача решается при принятом распределении вероятностей и линейной полезности денежной прибыли. Неполное доверие к распределению — отдельный анализ: H(q,ν) = ν E[П(q,D)] + (1−ν) min_D П(q,D). Для ν < 40/51 он выбирает q = 1, для ν > 40/51 — q = 2, на границе обе закупки равноценны по H. Параметр ν задаётся ЛПР и не является статистическим уровнем доверия.

Все расчёты магазина выполнены для исходного условия. Они не выдаются за примеры из книг. PDF, DOCX, сканы и извлечённые тексты учебников в репозиторий не включены.
